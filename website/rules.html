Protocol & Audit Catalog

7 MCP Tools, 4 Conflict Classes & Resources

TOOL · memory_record_episode

Record Immutable Engineering Episode

Stores an ADR, bug root cause, invariant, migration, incident, or session note linked to files and entity IDs.

TOOL · memory_upsert_fact

Upsert Bi-Temporal Fact

Writes (subject_id, predicate, object) with automatic supersession when singular=True.

TOOL · memory_compile_context

Compile Token-Budgeted Context

Ranks active facts and episodes using Okapi BM25 + 2-hop spreading activation within max_tokens.

TOOL · memory_query_entity

Inspect Entity Ego-Graph

Retrieves active and optional historical edges around any service, file, or component ID.

TOOL · memory_time_travel

Point-in-Time Snapshot (as_of)

Reconstructs the exact valid knowledge graph at any past ISO-8601 UTC timestamp.

TOOL · memory_verify_integrity

Verify SHA-256 Merkle Chain

Recomputes cryptographic hashes across every stored fact and episode to verify tamper-free persistence.

TOOL · cortex_audit_contradictions

Audit & Auto-Resolve Conflicts

Scans active facts for polarity, antonym, alias, or singular drift conflicts and optionally supersedes older claims.

CRITICAL · negation_polarity_conflict

Negation Polarity Conflict

Flags pairs like does_not_use_session_cookie vs uses_session_cookie on the same subject.

CRITICAL · antonym_object_conflict

Opposing Antonym Object Conflict

Detects opposing state pairs such as stateful vs stateless, encrypted vs plaintext, or enabled vs disabled.

HIGH · predicate_alias_conflict

Canonical Predicate Alias Collision

Normalizes surface variants (e.g., requires_isolation vs isolation_level) that assert conflicting objects.

HIGH · unsuperseded_value_conflict

Unsuperseded Singular Value Drift

Catches concurrent active facts with divergent values written with singular=False.

RESOURCE · cortex://graph/stats

Graph Counts & Schema Summary

Live entity, episode, active fact, and superseded fact counts.

RESOURCE · cortex://graph/integrity

Cryptographic Integrity Report

JSON SHA-256 verification status and Merkle root digest.

RESOURCE · cortex://episodes/recent

Recent Engineering Episodes

Latest ADRs, invariants, and root-cause records persisted to the graph.

PROMPT · architecture-briefing

Component Architecture Briefing

Compiles a token-budgeted briefing for a target service or module ID.

PROMPT · bug-investigation-context

Bug Investigation Context

Retrieves invariants, historical root causes, and dependencies for a symptom.
