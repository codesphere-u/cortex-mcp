TOOL · memory_record_episode Immutable SHA-256 Episode

Record Immutable Engineering Episode

Stores an ADR, bug root cause, invariant, session note, migration, or incident linked to touched files and mentioned entity IDs.

title* (string) category* (enum) content* (string) files_touched (string[]) entities_mentioned (string[]) timestamp (iso8601)
Inspect JSON-RPC 2.0 Request Example
json 
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "memory_record_episode",
    "arguments": {
      "title": "ADR-019: Migrate auth_service to PASETO_v4_public",
      "category": "adr",
      "content": "Replaced symmetric JWT_HS256 with Ed25519 asymmetric PASETO_v4_public.",
      "files_touched": ["src/auth/tokens.py"],
      "entities_mentioned": ["auth_service"]
    }
  }
}
TOOL · memory_upsert_fact Auto-Supersession

Upsert Bi-Temporal Fact

Records a directed (subject_id, predicate, object) triple with automatic conflict detection and closure of prior active facts when singular=True.

subject_id* (string) predicate* (string) object_id (string) object_value (string) singular (bool=true) confidence (number=1.0) source_episode_id (string) valid_from (iso8601)
Inspect JSON-RPC 2.0 Request Example
json 
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "memory_upsert_fact",
    "arguments": {
      "subject_id": "auth_service",
      "predicate": "signing_primitive",
      "object_value": "Ed25519_Asymmetric_Keypair",
      "singular": true
    }
  }
}
TOOL · memory_compile_context BM25 + 2-Hop Packing

Compile Token-Budgeted Context

Scores active facts and episodes via Okapi BM25 + 2-hop graph spreading activation and greedily packs items within strict max_tokens.

query* (string) max_tokens (int=1200) include_superseded (bool=false) as_of (iso8601)
Inspect JSON-RPC 2.0 Request Example
json 
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "memory_compile_context",
    "arguments": {
      "query": "auth_service token signing and payment_ledger isolation",
      "max_tokens": 800
    }
  }
}
TOOL · memory_query_entity Ego-Graph Traversal

Inspect Entity Ego-Graph

Returns an entity's active facts, superseded historical facts, related engineering episodes, and K-hop graph neighborhood.

entity_id* (string) include_superseded (bool=true) max_hops (int=2)
TOOL · memory_time_travel Point-in-Time Query

Point-in-Time Snapshot (as_of)

Reconstructs the exact active knowledge graph state valid at any past ISO-8601 UTC timestamp.

as_of* (iso8601 UTC string)
TOOL · memory_verify_integrity Cryptographic Audit

Verify SHA-256 Merkle Chain

Recomputes canonical SHA-256 hashes across every stored temporal fact and engineering episode and returns the graph Merkle digest.

No required arguments
TOOL · cortex_audit_contradictions Semantic Conflict Auditor

Audit & Auto-Resolve Conflicts

Scans active facts for polarity inversions, antonym objects, predicate alias collisions, or unsuperseded drift and optionally auto-supersedes losers.

as_of (optional iso8601) auto_resolve (bool=false)
Inspect JSON-RPC 2.0 Request Example
json 
{
  "jsonrpc": "2.0",
  "id": 7,
  "method": "tools/call",
  "params": {
    "name": "cortex_audit_contradictions",
    "arguments": { "auto_resolve": true }
  }
}
CRITICAL · negation_polarity_conflict

Negation Polarity Conflict

Flags opposing polarity claims on the same subject and canonical predicate, such as does_not_use_session_cookie vs uses_session_cookie.

CRITICAL · antonym_object_conflict

Opposing Antonym Object Conflict

Detects contradictory technical state pairs including stateful vs stateless, encrypted vs plaintext, mutable vs immutable, and enabled vs disabled.

HIGH · predicate_alias_conflict

Canonical Predicate Alias Collision

Normalizes surface variants (e.g., requires_isolation vs isolation_level, or db_engine vs database_engine) that assert conflicting objects.

HIGH · unsuperseded_value_conflict

Unsuperseded Singular Value Drift

Catches concurrent active facts written across parallel sessions with singular=False that hold conflicting object values.

RESOURCE · cortex://graph/summary application/json

Bi-Temporal Knowledge Graph Summary

Live counts of tracked entities, active vs superseded facts, recorded episodes, and the graph SHA-256 Merkle digest.

RESOURCE · cortex://graph/integrity application/json

Cryptographic Integrity Report

Full JSON SHA-256 verification status across all facts and episodes plus Merkle root digest.

RESOURCE · cortex://episodes/recent application/json

Recent Engineering Episodes

Array of the 20 most recent ADRs, invariants, and bug root causes persisted in the graph.
