Engineering FAQ

Design decisions & operational guarantees

Why bi-temporal tracking instead of a flat vector store?

Vector similarity treats deprecated config (like JWT_HS256) and its replacement (PASETO_v4_public) as equally true neighbors. Bi-temporal bounds (valid_from, valid_until, superseded_by) exclude superseded facts while preserving historical time travel via memory_time_travel.

What is the difference between the hosted Vercel endpoint and local stdio?

The hosted Vercel endpoint (https://cortex-mcp-steel.vercel.app/mcp) runs statelessly in memory per serverless instance for instant zero-install testing. For private, persistent project memory saved atomically to disk, run cortex-mcp serve-stdio --storage .cortex/memory.json.

How does Cortex-MCP integrate with TruthGate?

cortex-mcp export-sources (and export_truthgate_sources()) emit verified GroundedSourceDocument payloads carrying temporal provenance and the graph SHA-256 Merkle root so downstream verification gates can prove zero stale-fact citation.

How is tampering detected in local graph storage?

Every recorded episode and temporal fact participates in a canonical SHA-256 hash and deterministic Merkle root digest checked by memory_verify_integrity and exposed on cortex://graph/integrity.
