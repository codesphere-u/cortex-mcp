Cortex-MCP Documentation

Cortex-MCP (cortex-bitemporal-mcp) is a local-first bi-temporal knowledge graph, contradiction auditor, and token-budgeted context compiler exposed over the Model Context Protocol (MCP) JSON-RPC 2.0 specification.

Protocol Layer Responsibility in Agent Stack Cortex-MCP Implementation
MCP Transport Agent ↔ Memory Graph tools, resources, prompts CortexMCPServer over stdio, HTTP/SSE, Vercel Streamable HTTP
Bi-Temporal Graph Track valid time vs transaction supersession BiTemporalMemoryGraph with valid_from, valid_until, superseded_by
Context Compilation Rank & pack facts under strict token budget ContextCompiler (Okapi BM25 + 2-hop graph activation, 100% stale filter)
Grounded Verification Export provenance-cited source bundles export_truthgate_sources() for codesphere-u/truthgate

1. Installation & Quickstart

Run zero-install with uvx, install from GitHub, or clone editable for local development and tests.

bash 
uvx --from git+https://github.com/codesphere-u/cortex-mcp.git cortex-mcp demo
uvx --from git+https://github.com/codesphere-u/cortex-mcp.git cortex-mcp benchmark
bash 
pip install "git+https://github.com/codesphere-u/cortex-mcp.git@v1.2.0"
cortex-mcp --help
bash 
git clone https://github.com/codesphere-u/cortex-mcp.git
cd cortex-mcp
pip install -e ".[dev]"
pytest -v
✓
Package Naming Note: The PyPI distribution name is cortex-bitemporal-mcp (because cortex-mcp belongs to an unrelated package), while the CLI binary and import module remain cortex-mcp and cortex_mcp.

2. Transports: Hosted Streamable HTTP vs Local Stdio

Choose between the zero-setup public Vercel gateway for experimentation or local stdio / self-hosted HTTP for persistent project memory.

Transport Endpoint / Command Persistence & Privacy Recommended For
Hosted Streamable HTTP https://cortex-mcp-steel.vercel.app/mcp Ephemeral in-memory serverless instance (shared across warm callers) Instant demos, schema exploration, zero-install smoke tests
Local Stdio cortex-mcp serve-stdio --storage .cortex/memory.json 100% local atomic JSON file on disk, zero network egress Production coding workflows in Claude Code, Cursor, Claude Desktop
Self-Hosted HTTP / SSE cortex-mcp serve-http --host 127.0.0.1 --port 8000 Local or Docker container (supports POST /mcp & GET /sse) Shared team knowledge graph or remote agent runtimes
!
Hosted Ephemeral State Warning: All 7 MCP tools work on the hosted Vercel gateway, but state is per-instance and ephemeral. Always pass --storage .cortex/memory.json via local stdio for private, durable engineering memory.

4. System Architecture

Cortex-MCP routes JSON-RPC 2.0 tool, resource, and prompt calls cleanly into two deterministic core engines backed by atomic JSON snapshots.

5. Bi-Temporal Graph Model

Every TemporalFact stores both valid time (valid_from, valid_until) and causal supersession lineage (superseded_by). When memory_upsert_fact writes a singular=True fact for an existing (subject_id, predicate) pair, the prior fact is atomically closed without erasing history.

  • Point-in-Time Inspection: memory_time_travel(as_of) reconstructs active architecture at any historical UTC timestamp.
  • Tamper-Evident Persistence: Canonical SHA-256 hashes over every fact and episode feed a deterministic Merkle root digest checked by memory_verify_integrity.

6. Okapi BM25 & 2-Hop Context Compiler

ContextCompiler splits snake_case, CamelCase, and file paths into sub-tokens, scores candidates with Okapi BM25 plus exact identifier boosting, activates 2-hop graph neighbors across active edges, and runs greedy utility-density packing under max_tokens with 100% stale-fact suppression.

7. Semantic Contradiction Auditor

ContradictionAuditor scans active facts to catch four conflict classes: negation_polarity_conflict, antonym_object_conflict, predicate_alias_conflict, and unsuperseded_value_conflict. Pass auto_resolve=True or run CLI --auto-resolve to deterministically supersede older or lower-confidence claims.

python 
from cortex_mcp import audit_contradictions, export_truthgate_sources

report = audit_contradictions(graph, auto_resolve=True)
print(report.summary_markdown)

8. TruthGate Grounded Export

Export compiled context packets or active graph facts into TruthGate-compatible GroundedSourceDocument JSON arrays carrying temporal provenance and graph_merkle_digest:

bash 
cortex-mcp export-sources --query "auth_service uses_token_format" --max-tokens 1200 --output sources.json

9. CLI Subcommand Reference

All 7 CLI subcommands defined in src/cortex_mcp/cli.py:

Subcommand Key Flags Purpose
cortex-mcp demo --json Run multi-session supersession & time-travel demo
cortex-mcp benchmark --facts 500 --episodes 100 --json Measure P50/P95 latencies & stale-fact suppression
cortex-mcp serve-stdio --storage PATH --seed-demo Start JSON-RPC 2.0 MCP server over stdin/stdout (alias: mcp)
cortex-mcp serve-http --host 0.0.0.0 --port 8000 --storage PATH Start local HTTP & SSE MCP transport server
cortex-mcp audit-contradictions --storage PATH --auto-resolve --json Scan active facts for logical/polarity contradictions
cortex-mcp export-sources --storage PATH --query STR --max-tokens 1200 --output FILE Export TruthGate SourceDocument JSON bundle
